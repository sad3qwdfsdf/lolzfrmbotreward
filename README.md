# LOLZ Forum Bot

Бот для автоматической раздачи ключей в комментариях на форуме LOLZ.

## Возможности

- Автоматическая проверка новых постов в теме
- Раздача ключей в комментариях
- Отслеживание уже отвеченных постов
- Проверка активных комментариев
- Сохранение прогресса работы
- Подробное логирование

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/lolz-forum-bot.git
cd lolz-forum-bot
```

2. Создайте виртуальное окружение и установите зависимости:
```bash
python -m venv venv
.\venv\Scripts\activate  # для Windows
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и настройте его:
```bash
cp .env.example .env
```

4. Создайте файл `data.txt` и добавьте в него ключи (по одному на строку)

## Использование

1. Активируйте виртуальное окружение и запустите бота:
```bash
.\venv\Scripts\activate  # для Windows
python main.py
```

## Структура проекта

- `main.py` - основной файл бота
- `.env` - файл конфигурации
- `data.txt` - файл с ключами
- `replied_users.json` - файл с историей ответов

## Требования

- Python 3.7+
- Токен LOLZ API
- Доступ к форуму LOLZ

## Безопасность

- Не публикуйте токен и конфиденциальные данные
- Используйте прокси при необходимости
- Следите за логами в `bot.log`
